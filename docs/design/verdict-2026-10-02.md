# Whole-product verdict (2026-10-02) — EVOLVE, not redo

> What this is: the whole-product verdict of 2026-10-02 that chose evolve over redo. It records why, what must be kept, and the Are.na reference lock with its reject list.
> Status: live reference for the keep list and reject list, history for the rest, last edited 2026-11-03.
>
> Outcome: Kyle took all six forks as recommended (see `docs/design/brand-iteration.md`). The fixes have landed, so the problem list and the plan are cut. NeighbourhoodCover as described below is superseded by the woven cloth. The welded agent mark is superseded by the seal. The left-anchored column is now the centred `PAGE_FRAME` (`lib/frame.ts`).

Panel: 7 blind Fable judges ({'evolve': 7}, mean 6.4), 2 skeptics (neither refuted), 5 reference angles (35 candidates, 31 verified as claimed, 4 slightly overstated, 0 invented).

## Decision
不推倒重做。七位盲评评委、两位怀疑者、五路参照研究全部独立得出同一个结论：骨架是资产，签名缺位。暖石纸面、唯一的 forest 绿、全无衬线、发丝线上的开放行、真正调过的暗色、形状 = 种类的标记字母表、Decision 页的编辑排版——这些在 26 帧里零冲突，大多数团队做不到，redo 等于清零再建一次同样的骨头。分数卡在 6.4 的原因有三处，都在语言之内。一，图是产品名字承诺的东西，却画成了每个知识工具自带的灰色默认图——代码里来源编码是有的，只是 0.8–1.2px 的线和 2.2 的虚线在 1440 宽下读不出来，也没有“确认了几次”这根轴。二，首页最大的一块像素是一张什么都不编码的渐变封面，是全产品最像 AI 模板的东西，手机上占满首屏，暗色下标题看不清。三，唯一属于 Woven 的字母表只出现在两张屏上，行、侧栏、⌘K 里都没有，agent 头像被当项目符号用。再加一层：评委以为缺的“基元层”（页头、行、确认权重、状态）其实大半已经写进规则没落地——forest 权重补丁、Library 行换 Contents 语法、去 ⓘ 去提示句、Valve 图标——落地就是。所以是 evolve：删渐变、把图做成签名（幅度 + 证据线宽）、字母表推进行列、落地已写的规则、清掉中点/哈希/解释句这些生成痕迹。锚定对象选 Are.na——“连接就是内容”本来就是 Woven 的论点，它也是唯一不在 Linear/Attio/Notion 那根轴上的顶级参照；图借 Kumu/Heptabase 的“地图是场所”，agent 渲染借 Granola 的“署名一次、墨色即判定”。不换代码库。六个分叉要你拍板，列在下面。

## Is ~6 a ceiling?
主要是方法的天花板，但附一个条件。证据有三。(1) 过去四轮循环（21 / 8 / 9 / 4 回合）每次卡在 5–6.5，剩下的缺口三类都一样——你的既定决定、无记忆评委每回合重新裁一次的结构分叉、静帧看不见的 hover——AGENTS-additions 里三处方法备注说的是同一件事；agent mark 那轮从 4.9 推到 ~7 之后在 6.5–7.2 之间“评委在同一根轴上来回翻”，文档自己把这叫做“需要一个几何之上的决定”。(2) 这一轮 7 位评委 6.0–6.5，但排最前的两个问题（图、封面）七个人一致，说明分数不是噪音，是同一处缺口被七个镜头各扣一次——第二位怀疑者算过，渐变一个组件被扣了七次，页头和确认的分叉也被数多了，均值大概低了半分。(3) 绝对分评委做的是“一眼对标顶尖”，能动一眼分数的是签名和层级，不是 token 纪律。Woven 过去几个月的投入在 token、字阶、alpha 墨家族、按钮权重规则上——这些评委看不见；没投在评委看得见的两样东西上：图的幅度和封面。所以 6 是“规则写了没落地 + 签名还只在两张屏上”的分数，不是这套语言的上限；语言本身已经被 Decision 页和 review dialog 证明能承载权威和密度。条件：第 1–3 步落地（封面换掉、图的幅度、字母表进行列）之后再盲评一轮，均值应到 7.5–8。如果到那时仍钉在 6.5，怀疑者一的测试就成立——单一 forest 口音在结构上压住了图的表达力——redo 重新开庭。还有一个方法结论：绝对分循环不要再当主仪器，六个分叉用 pairwise + 你拍板，绝对分只在分叉修完后做一次 checkpoint，之后停。

## Keep

- All-sans Geist with the type ladder bound in one @theme block, and the Reading register (19 / 22 / 40) that makes the reader and the Decision page distinct by size and measure, not by a serif.
- Open rows on inset hairlines (DIVIDED), minimize-cards, the left-anchored page column — at the Linear/Attio line already (craft, redo, keep).
- The mark alphabet — shape = kind, size = depth, hue = identity, line = provenance — the one unmistakably-Woven idea, legible in Topics unfolded and seeded in the hub glyph (brand, taste, redo, keep).
- The welded agent mark on the forest dish, and the rule that status marks are circled while the agent is never ringed.
- The Decision page register: eyebrow → display title → one plain sentence → 2×2 truth grid → people and evidence (every judge names it the best surface).
- The /team review dialog: grouped by subject doc, confidence as a word, ✓/✕ valve per row, one 'Confirm all N' per group, 'Verify on the map' as the escape hatch.
- Dark as a re-ramped theme (raised = lighter, forest → sage, ochre survives), not an inversion.
- The Collection Contents rail drawn per row (Fable-panel settled 09-14) and the phone reflows of the collection list and reader.
- The textless reading-outline bars; the capture sheet (one field, one verb, one solid commit); the written product voice with no 'Welcome back'.
- The rule set itself: forest-action weight, Valve, alpha-ink family, confidence-at-rest, explorer shell — the primitive layer the judges called missing is largely written; the work is landing it.

## Reference lock
**Primary:** Are.na (the channel page, e.g. are.na/charles-broskoski/arena-influences; verified): the connection is the content. Sharp traits that survive untouched: a connection drawn as a first-class fact ('This channel appears in' as its own column, not a count), a hairline-ruled metadata band under the title, a breadcrumb title with earlier steps greyed, one face, no status chrome, blocks whose content is the document's own text. It is the only top reference off the Linear/Attio/Notion axis the shell already sits on, and the only one whose thesis is Woven's own. It anchors the public pages, the reader's metadata band, the Library grid tile and the no-links cover. It does not anchor the Inbox or the confirm loop (the house grammar governs those) and it has no graph; the graph's signature is built from Woven's own alphabet with two narrow borrows.

Preserve:
- A link is drawn, never only counted: a 'Woven into' band replaces the rail's stacked Sources 3 / Links 4 / Decisions 4.
- The severe register on reading and public surfaces: one face, hairlines, no status chrome, no decoration, no card around a list.
- Breadcrumb as title with earlier steps greyed — the explorer eyebrow → h1 already does this; extend it to the public pages.
- A tile with no image shows the document's own first paragraph in the reading face — the honest fallback for a cover with no confirmed links.
- Captions and meta set with space and hairlines, never a separator glyph.

Borrow:
- Kumu / Heptabase (narrow — graph only; both verified): the map as a place. A two-row edge key readable cold (dashed = proposed, solid = confirmed) as a hover key in the field's corner; opening a node keeps the map visible (the in-place unfold already settled, a right pane for the full document); on the Team field only, a collection named as a floating region label in its own hue rather than a leaf square. Not their cards, not their colour volume.
- Granola (narrow — agent rendering only; tokens verified): the agent credited once per surface in a byline (AgentBand), rows carrying the proposal not the author; the verdict visible in the text — a proposed claim's words in muted ink until confirmed, inside the existing wash + line-wash surface, so confirmation reads as ink arriving rather than a button appearing; every agent claim one click from the sentence it came from (the ⌘K cited-answer rule). Not its serif, not its olive.

Reject:
- More Linear / Attio / Notion in the shell — the safe average that produced 'Linear in warm paper'. Linear's dark command-centre default, lime and Berkeley Mono; Attio's cool grey and Tiempos; Notion's blue suggestion ink.
- Any serif or italic display (Granola Quadrant, Attio Tiempos, Midday Hedvig Letters Serif, mymind) — collides with 'All-sans is LOCKED'; the display step the judges want already exists (text-3xl 44, read-display 40). Also the fastest way to converge on the 2026 'tasteful AI notes' look.
- Heptabase card-nodes and saturated pill regions — would replace the mark alphabet with cards; collides with minimize-cards and the accent budget.
- Kinopio colour-per-edge-type, Attio traffic-light confidence dots, Notion blue — a fifth hue; collide with 'forest only for proposed / confirm' and ConfidenceWord.
- Arc / Raycast / Vercel-template gradient covers, Delphi glowing radial graphs, Cosmograph — the glow and gradient the alphabet bans ('no ambient gradient, halo, drop-shadow or hover spotlight').
- Tana's look — a direct competitor making the same 'decision + owner + why + source' claim; borrow nothing visible.
- The brand judge's time-ordered warp layout — collides with 'rings by KIND' and orbit-bench; the layout is already deterministic.
- A centred bounded ⌘K — collides with 'Full-screen takeover, never a centered palette'; fill the takeover instead unless the owner reopens the rule.
- React Flow as the renderer and tldraw (NOASSERTION licence) — the house layout, label seating and alphabet are the asset; React Flow ships no layout and its defaults read as a React Flow demo.
- Teenage Engineering's 100–300 weights at UI sizes (fail at 12–13px and in dark) and 0px radius — take only the conviction that an alphabet is a brand when used without exception, which is already the house rule.
- OpenStatus mono-everywhere (collides with 'mono = the agent's voice'); mymind masonry for a text corpus; Dia's frosted translucency; Midday's AGPL code (study the sentence-as-widget grammar, copy nothing).

**Code base:** none — keep the current codebase. Next 16 / React 19 / Tailwind 4 / Base UI 1.5, 446 commits, ~20k lines of components carrying the token system (the alpha-ink family bound in one @theme block), the primitives (DIVIDED, Valve, SegToggle, ViewTabs, FeedHead, StatusPill, NodeMark, AgentMark), a custom SVG graph renderer with the orbit layout, label seating with ground knockout and scripts/orbit-bench.mjs, and a design lint (scripts/check-design-rules.mjs). The codebase researcher found no open-source product with better taste than Woven's own language: Midday is the only top-tier one and it is AGPL, Tailwind 3 + Radix. Borrow components, not a base: coss ui apps/ui (MIT; Base UI 1.8 + Tailwind 4.1 — the same stack) for Combobox / Autocomplete / Toast where Woven lacks them, restyled with house tokens. The graph stays on components/local-graph.tsx: an amplitude pass on ~1,900 lines that already encode provenance and seat labels is cheaper and safer than porting the orbit-bench invariants to React Flow.
