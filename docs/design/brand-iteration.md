## 1. 现在的 Woven 是什么样子

暖石纸面。浅色底 #f1f1ee，卡面 #fafaf8，从不纯白。暗色是暖炭 #1a1815，侧栏比画布再深一档，中间不画线。全站一个强调色 forest，浅色 #365e33，暗色提到 sage #6fb58a，只给 chrome、agent 和确认动作。中性填充全部走透明墨的命名 token（tint-1/2/3 = 6/10/14%），同一个 class 在两个主题里都成立。forest 的填充只有三处：wash 4%（必配 15% 发丝线）、mark 10%，以及 Button 的 confirm 变体 6/10/14（暗色 10/14/18，配 40% forest 边线），后者是 globals.css 唯一允许手写的 alpha。全无衬线，Geist 承担 UI、标题和阅读；Geist Mono 只给 agent 自己的话、代码、真实值和键帽。字阶绑在一个 @theme 块里（12/13/15/17/20/28/44/64，阅读层 19/22/40），字重只有 400 和 500，页面标题统一 28，详情页带面包屑。列表是发丝线上的开放行，卡片只给浮层、Library 封面卡和 callout。公开的 artifact 页走 Are.na 的语法：标题上一行眉题，一条发丝线的元信息带，没有卡，发布者是字母盘，没有圆点。

一套标记字母表贯穿图、经络和行首。形状 = 种类，大小 = 深度，色相 = 身份，线型 = 来源。来源（source）是空心环，纸色在里、色相在线上，是字母表里唯一空心的东西。虚线是 agent 的提案，实线是人确认过的，确认那一下虚线焊成实线。图坐在页面自己的列里，没有井、卡、边框或 ⓘ。

agent 的身份是一枚 seal：forest 圆盘（color-mix 70% 混到底色）上挖出一条纸色的波线，峰谷峰加一段收尾，占盘宽 70%，没有独立的节点。它就是 logo 结尾那个节点长大托住了波。人是暖半轮六个色相（sage、ochre、rose、clay、gold、moss）之一的实心圆盘加一到两个字母，fill 是色相 20% 叠在卡面上，ink 是色相 36% 混向前景，没有环。登录用户 Maya 是 clay。集合和主题保留十二个色相。+N 折叠片是不透明的 tint-1 圆盘，无边框，灰 500，头像堆和集合标签共用一个对象。

文档封面是一块布。最早上线的版本（aa76634）经线是章节，纬线是已确认的链接。10-07 上线的收敛版（L3，2fa012a）：经线仍是章节，取集合色相；地纬是安静的双色，只说这里有链接；只有锚在章节里的链接浮在布面上，最多 4 条、最多 2 个邻居色相，是布上唯一的颜色。全站一个线数，织距随盒子走。Library 卡上是一条布带，首页 hero 是一小块布样放在 tint-1 的衬底上。锚定参照是 Are.na。连接就是内容。

现行版本（5369ae4，Cover: the window cloth on every surface，Kyle 选定，不再改回环形）：封面是一扇窗，看到的是文档自己的布。织距固定，一根经线约 8px，缝 1px，盒子越大看到的布越多，线不变粗。经线是章节，宽度随字数；纱线取卡片 chip 领头的集合色相，未归档的文档不染色；文档一有已确认链接就多一层平纹地纬；最强的两条链接以邻居色相浮起。没有链接的文档只有经线。提案链接、读者打不开的邻居和文字都不画。Library 卡是 3:1 头部里的一条带，Continue hero 从 sm 起是这条带的盒子（230×75.66）放在 tint-1 衬底上，手机上是满宽带。

## 2. 定下来的原则

只列仍然生效的。被推翻的在本节末尾单列。括号里是来源。

### 颜色与墨

- forest 只给 chrome、agent、确认。导航、选择、创建、开关、已定状态都用墨。一屏最多一个实心 forest。（09-03 Open Inbox 扫描，「这种类型的按钮我也希望你在系统里面都扫一遍，按顶级工作室标准来去用 fable 评审，并且去提高一下设计，目前看来这个样式不对」；09-04「开关改墨色，然后把 /team 三点共线也修掉」）
- 确认按钮的权重由动作本身决定，问三个问题。写入记录吗，作用于多个对象或在列表里重复吗，是 ✓/✕ 的一半吗。答案落到 SOLID / WASH / NEUTRAL。永远不参照旁边的控件。（09-04 b847f97，「这两种类型的 button 也都要定好设计，不要改来改去。你也查一下其他类似的 ghost design 的 button」）
- 三条推论不再重议。权重跟范围走，作用于更多对象的控件永远不比作用于更少对象的轻。一个控件一个动作，动词随状态变的按钮是两个控件。SOLID 的提交永远配一个 ghost 的取消。（AGENTS-additions §Forest action weight）
- hover 只加深。浅色变暗，暗色变亮。改色调，不改位置。禁 opacity-80 一类的变淡。（09-03 ffa41cb，--primary-hover 从 #41693e 改到 #2d5029）
- 中性填充按角色取 tint-1/2/3。forest 填充只有 wash 4%（必配 15% 发丝线）、mark 10% 和 Button confirm 变体的 6/10/14。不手写 alpha，有 lint。（09-05 6b111fe；ui/button.tsx）
- 坐在地面上的东西用透明墨。嵌在东西里的（轨道、井、骨架）才允许下沉。（09-04 f1410a6）
- 暗色里选中等于凸起，凸起等于更亮。（09-02 33ca38a，「这里暗色模式的选中状态似乎有一些问题，应该是 lighter color 而不是 dark color」）
- 品牌色永远不是数据系列色。单系列数据用中性墨，陈旧状态用 --warn。（07-29 cb33e20）
- 静止的控件永远不能比选中的控件更响。控件靠填充读出来，不靠描边。（09-02 b8f74cb，「这两个组件底下最好也要加一点 lightshade，这些组件的分级逻辑和信息要明确」；07-19 3fc8fac）
- 深度靠色调。没有阴影堆叠，没有渐变，没有光晕。（09-04 字母表清掉 glow stack；10-02 VERDICT）

### 字

- 全无衬线锁定。Geist 承担 UI 和阅读，阅读层靠字号和行距区分。（07-11 锁定；07-23 c9fde58，「字体需要使用我们设计系统里面的」「然后你做一次全库迁移吧」）
- Geist Mono 只给 agent 自己的话、代码路径、真实值、键帽。署名、计数、状态、时间戳都是 Geist。对齐用 tabular-nums。（07-23 34b2e77）
- 字阶一个声明。xs 12，sm 13，base 15，lg 17，xl 20，2xl 28，3xl 44，4xl 64，阅读 19/22/40。没有 14、16、24、30。（09-05 ce986e2）
- 行高归字阶，站点不写 leading。只有盒子即字形时允许 leading-none。（09-05 f66a642）
- 字重只有 400 和 500。强调靠字号和墨。（08-16 零违规）
- 页面标题全站一档 28。详情页标配面包屑，索引页不要。（09-02「详情页面包屑做成标准，其他 detail 页都补上」；09-05 升到 28）
- 控件、标签、菜单在 sm 13。层级靠形状和 forest 下划线，不靠字号。（09-02「这里的字体似乎可以小一点？」「这个里面的文字要变小一些」；09-05 并到 13）
- 分区标题和行标题同档（15/500），靠留白分开。（09-04 字阶 panel）
- 文字上阶梯，标记按比例。头像字母约 0.42 到 0.45 圆径，不进字阶。（08-15 46db5df；07-29 d79ab88，「还有这个 avartar 里面文字，现在过于顶格了」）

### 控件与圆角

- 三种控件角色各一种材料。ViewTabs（下划线）管看哪个视图，SegToggle（轨道加拇指）管当前视图的设置，切换主体放在标题里（名字加小 chevron）。（07-29 cb78869；09-14 Topics，「目前看来是三种相同的认知功能路径的 按钮」）
- 分段控件是凹陷轨道加凸起白拇指，没有边框。（07-19 3fc8fac，「这个控件不行，边缘太明显了，同样第二个的选中态没有和周围背景区分出来」）
- 圆角四档。sm 4 标记，md 10 控件，lg 16 面板，full 形状。没有比面板更圆的东西。控件堆里的方块用控件档。（08-15；09-03 71b6118，「这里最好都是要做成圆角矩形」）
- 可点的东西静止时就要像按钮。有底色，圆角矩形，hover 更深。（07-30 c4225a1，「需要加上底下的 base color，加成圆角矩形」）
- 稀少的破坏性动作降级，但不剥掉按钮感。软底色加语义图标，hover 才变红。（07-30 Unpublish）
- 过滤器不能长得像标签页。分段控件不放在视图标签正下方。（07-22 ed92db4）
- 开关是设置，用墨色轨道。（09-04 d635ffb）
- 图标按钮走 IconButton，label 同时是 aria 和 tooltip。没有名词的元素必须有 tooltip，tooltip 说名词不说动作，附 sr-only。（07-29；09-02 4820eff，「这个有点看不懂什么意思，我认为需要组件化同时加 tooltip」）
- 点击区域 36 到 40px 起，与视觉盒子无关。（07-17 320eeb4；07-19 84141fc）
- 手机上每个交接控件 ≥44px。移动端触发器的那条带归 layout（SidebarInset max-md:pt-14），不归页面框架。固定的侧轨在断点以下折叠。（AGENTS-additions §Home、§Responsiveness）

### 行、列表、卡片

- 少用卡片。内容列表是开放行加发丝线，图画布是无边的场。卡片只给浮层、Library 封面卡、callout。（07-21 23e2ddc，「我们目前的设计会尽量减少使用卡片」）
- 任何组件不做左缘色条或左侧发丝竖轨。那是 AI 模板的痕迹。状态和分组走 chip、图标、圆点、底色。09-03 Library 选择模式下 checkbox 挪进页边，40 行一起亮成一条左侧竖列，正是这条否掉的。
- 行分隔线用共享 DIVIDED，内嵌。包裹面内嵌，结构缝通栏。（07-29 306431c）
- 同一个对象到处长一样。场景行只能在身份骨架上加信息，不能替换。（07-23 collection 行）
- hover 只能加控件，不能拿走信息。不可见的控件不能还能点。验收是状态乘行数，不是一帧。（09-03，「这里有一个 hover 态的问题，hover 会挡住设计。」）
- 散文流动，标记挂第一行，只截断一键之外有完整形式的东西。（09-12 569e6c3，「还有这种简单应对 responsiveness 的方式我觉得也有问题」）
- 带列表的对话框顶部锚定，一条文字左边，用系统 Dialog。（09-13 65aec53）
- 行的状态是一个词。不是圈，不是色点。（09-13；09-14 StatusPill）
- 开放列表不要表头。（09-14 8854776，「这一块可以删掉」）
- 行分隔线从文字列开始，不穿过竖线。（09-14，「这一块需要解决 divider 和垂直线条打架的问题」）

### 数字与文案

- 小数字分三种，墨色说明是哪种。demand 全墨 500，inventory 灰 400，fold +N 在 tint-1 底上。地面上的数字不进 pill。（09-10 cd4d60b，「这个里面的数字是否可以去有更好的设计？」「这个 +1 的设计也要更加好看」）
- 选择控件里的计数例外。SegToggle、ViewTabs 的 tab 上，计数穿 tab 自己的墨，小一档，不走 demand / inventory 那套。调用方永远不给计数上色。（09-12 裁定，AGENTS-additions §Small numbers）
- 分区尾部动作一种形式。灰静止，hover 全墨，结尾一个动词符号（→ 或 ⌘K）。（09-10，「这一系列的按钮看一看能怎么办？」）
- 计数必须等于它打开的行数。数字只有一个来源，排序规则句从排序表生成。（09-04 aedcf73；09-15 Team 的 11）
- 置信度静止时是一个词，只在需要时出现。高不显示，Likely 灰，Unsure 全墨。百分比只在 hover。（09-12 e30abdc，「这里的可视化方式确定是最好的么？」）
- 不用中点分隔，用空格、发丝线或逗号。不用破折号替代。有 gate。（07-31 5df01b2，「这里的 copy 可以不要过度使用 “·” 的符号么，这个不符合习惯，这个问题也不要录进 copy 里面」；09-03 64df4a4）
- 页头没有 ⓘ、解释句、常驻图例。解释进 hover。（07-23 09faaa8，「知识图谱一直有显示这个部分，需要修一下」；10-02 整产品评审，七位评委都把「Needs you」下面那句排序说明读成 AI 在解释界面，这是评审综合里的转述，不是谁的原话）
- 分区标题说读者在哪，不说机制。「Ask Woven」取代了「Ask your collective brain」。（09-04 89f9a03）
- 文案不夸大产品没有的能力。没有假托管，没有假阅读数。（09-02 评估）
- Toast 标题是过去式陈述，按钮是命令式。（09-03）
- 无用字段删掉。（07-17 5a21a09，「这一行字段是没有必要的，消除后底下的自动提上来」）

### 标记字母表与图

- 一套字母表，四条轴各一个任务。形状 = 种类，大小 = 深度，色相 = 身份，线型 = 来源。圈起来的是状态。色相从不编码状态。（09-04 b4311c9 fd5c930，「设计整体需要统一，不同元素之间的矛盾要解决好，不要打架」）
- 来源是空心环。纸色在里，色相在线上，一个起点在底座之外。人和来源原来都是实心盘，一个字母上压了两种意思，一份转录读成了一个人。字母表里只有它空心。（10-03 8619598；local-graph.tsx）
- 来源到处可见。未确认的 agent 链接永远是 forest 虚线，人确认过的是实线。确认时虚线在 240ms 里焊成实线，同拍文字从灰到墨。这是唯一的签名动作。（09-03 collection 评审；10-03 8619598）
- 线宽带意义。确认 1.5px，证据 ≥3 的 2.5px，提案 1.5px 的 4-4 虚线。越远的环越淡。名字 13px，最小标记 8px。（10-03 8619598，收尾 764510c）
- 图的场没有自己的底。它是从页面列里切出来的一个盒子，左边是标题的 x，右边是列的边距，上面在 tab 行发丝线下一个行高，下面到列的底部内距。图形放在盒子里的 0.47 高度，挂在标题的边上。--graph-ground 就是页面底色。没有井、卡片、边框、ⓘ。（09-15 四轮 920356f → df60e41；explorer.tsx）
- 不画死控件。Team 没有第二环就没有深度控件，只有一个 workspace 就没有切换箭头。（09-15 68df1bd）
- 深度从图里长出来。+N 折叠片挂在节点上，hover 预览，点击展开，已有的东西一个像素不动。（09-15 975e317，「我觉得最好能够是通过用户和 knowledge graph 的交互去逐渐延展的设计。这样从用户的认知 flow 里面会更加 intuitive」）
- +N 折叠片是一个共用对象。头像、集合标签、图节点都用它，是房子的 chip，不透明 tint-1 底。溢出折进 +N，不缩小标记。（09-10 cd4d60b；09-15；10-03）
- 图节点的详情是锚在节点上的 popover，列表行的详情是原地展开。重新居中是显式的 Focus here。（07-19 b39174a 497cd1d，「实际上更加适合的做法肯定是去做 popover」）
- 名字选边。背景色描边做 knockout，线从名字后面断开。这不是光晕。（09-04 af30790 eb80bce，「ego 图的名字选边也接上去」「knockout 也做上去」）
- /team 按种类分环。渲染器的半径是真值，布局用 orbit-bench 打分。（09-04 4d9fedc，「把 /team 三点共线也修掉」）
- 图里的 hover 亮节点和它的邻居，其余后退一档。几个 +N 同时打开时不是聚光，不能把别的展开压暗。（local-graph.tsx；10-03）
- 经络里的 hover 只亮真正相连的 tick，亮区之外的行保持静止的墨，不后退。压暗它们读成「禁用」。（09-14 a111114）
- 经络静止一种墨（hint 灰 3.2:1），重量只在 hover 时以集合色相出现。唯一例外是 agent 提案的虚线：forest，3-3 虚线，任何状态都是全强度（3.4 到 7.5:1）。主干、确认的 tick 和节点都是 --foreground-hint。没有链接的行静止时不画标记，hover 时节点以色相出现。（09-14 4ed5a4e，「这个设计目前看来默认状态下样式太“solid”了，，可以更加轻盈一些？」；collection-weave.tsx）
- 图例用画布自己的原语画，放在 hover 的角落键里，只列画了的东西。（07-23 d9565ee，「这个样式案例也需要 update 了，目前和 kg 完全脱节」；10-03 764510c）
- 被提到的实体都可以 hover，hover 时一对一显示它指代的东西。（07-17，「这些字段需要具有交互性，也就是 hover 后可以 1-1 展示对应它们指代的信息」）

### Agent 与身份
